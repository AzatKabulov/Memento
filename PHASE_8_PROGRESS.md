# Phase 8 — everyday controls and portable diary

Phase 8 is underway. Native settings now store an account-scoped reminder time and calendar-video autoplay preference in SQLite. The optional reminder uses local notifications for the next 14 unsaved dates, cancels a scheduled date after a save, and refreshes on app activity, diary changes, and a periodic foreground check. The settings screen reports denied notification permission and opens system settings. Storage usage counts active saved media. Help and privacy copy explains the current personal-only behavior; the existing dark appearance remains the only finished theme.

The native app can share an individual saved media file or create a full `.tar` diary archive containing original saved files and a versioned manifest with dates, captions, framing, media sizes, and checksums. Export and import stream files in bounded chunks, show progress, check free space, support cancellation, and remove temporary files. Before import, Memento checks every archive header, path, size, and media checksum. The user chooses whether matching dates are skipped or replaced. Dates already imported remain in the diary if an import is stopped or fails. Archives are **not encrypted**; anyone with a copy can read their contents. The browser remains a sample preview without device file access.

Remaining before the Phase 8 completion gate: run reminder permission, time-zone, daylight-saving, and notification-limit tests on iPhone and Android; export and restore a real mixed-media diary on both platforms and compare dates, captions, and media playback; test low-storage and interrupted-import behavior on devices; and build and validate a light appearance theme if that option is offered. A JavaScript bundle and unit tests cannot prove the native notification or share-sheet behavior. Account deletion remains a Phase 7 dependency and is not exposed as a control.
